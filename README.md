# analisis-sentimen-medsos-lapor-mas-wapres
Projek ini bertujuan untuk melihat sentimen warganet pada platform X (Twitter) sekaligus untuk memenuhi Final Exam mata kuliah Penambangan Data. Analisis yang dilakukan meliputi sentimen warganet, topik pembicaraan, serta Social Network Analysis (SNA) dengan menggunakan Gephi
